# Spam vs Ham Classifier

A Natural Language Processing (NLP) application designed to classify messages as either "Spam" or "Ham" (legitimate). Built using TypeScript to provide a strongly-typed, scalable classification engine.

## 🚀 Features
- Text preprocessing (tokenization, stop-word removal)
- Fast classification inference
- TypeScript-based architecture

## 🛠️ Tech Stack
- **TypeScript**
- **Node.js**

## ⚙️ How to Run
1. Install dependencies: `npm install`
2. Run the development server: `npm run dev`
3. Send a POST request with the text payload to test the classifier.
